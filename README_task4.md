# Задание 4: RAG-бот с техниками промптинга

## Описание

Реализован полнофункциональный RAG-бот, который:
- Ищет информацию в векторной базе знаний (из задания 3)
- Формирует ответы с опорой на найденные данные
- Применяет техники улучшения качества ответа: **Few-shot** и **Chain-of-Thought**

## Используемые технологии

### LLM
- **Провайдеры:** 
  - **OpenAI API** (по умолчанию) - облачный сервис
  - **Ollama** (альтернатива) - локальные модели, бесплатно, без API ключей
- **Модель по умолчанию:** 
  - OpenAI: `gpt-4` (лучше работает с русским языком)
  - Ollama: `mistral` (хорошо работает с русским языком)
- **Рекомендации для русского языка:**
  - OpenAI: `gpt-4` или `gpt-4-turbo` (лучшее качество)
  - Ollama: `mistral` или `llama3.1:8b` (хорошее качество русского)
  - См. `RUSSIAN_MODELS_GUIDE.md` для подробностей
- **Альтернативы:** Можно легко адаптировать для YandexGPT или других провайдеров

### Векторный индекс
- Используется векторный индекс из задания 3 (ChromaDB)
- Автоматическое расширение запросов и восстановление терминов

## Установка

1. Установите зависимости:

```bash
pip install -r requirements_task4.txt
```

2. Убедитесь, что векторный индекс создан (из задания 3):

```bash
python build_index.py
```

3. Настройте LLM провайдер:

**Вариант A: OpenAI API** (требует API ключ)
```bash
# Windows (PowerShell)
$env:OPENAI_API_KEY="your-api-key-here"

# Linux/Mac
export OPENAI_API_KEY="your-api-key-here"
```

**Вариант B: Ollama** (бесплатно, локально, без API ключей) ⭐ Рекомендуется
```bash
# 1. Установите Ollama: https://ollama.ai
# 2. Запустите сервер: ollama serve
# 3. Загрузите модель: ollama pull mistral
# 4. Настройте переменные окружения:
$env:LLM_PROVIDER="ollama"  # Windows
export LLM_PROVIDER="ollama"  # Linux/Mac
```

См. `setup_ollama.md` для подробной инструкции по Ollama.

## Использование

### Интерактивный режим (REPL)

Рекомендуется для начала работы:

```bash
python rag_bot_repl.py
```

Команды в REPL:
- `/help` - Показать справку
- `/exit` или `/quit` - Выйти
- `/verbose` - Переключить подробный режим
- `/fewshot` - Переключить Few-shot примеры
- `/cot` - Переключить Chain-of-Thought
- `/status` - Показать текущие настройки

### Программное использование

```python
from rag_bot import RAGBot

# Инициализация бота
bot = RAGBot()

# Простой запрос (используем термины нового мира)
answer = bot.chat("Что такое Crimson Lens?")
print(answer)

# Детальный запрос с настройками
result = bot.generate_answer(
    "Какие способности даёт Crimson Lens?",
    use_few_shot=True,  # Использовать Few-shot примеры
    use_cot=True,       # Использовать Chain-of-Thought
    k_chunks=5          # Количество релевантных чанков
)

print(result['answer'])
print(f"Использовано чанков: {len(result['context_chunks'])}")
```

## Техники промптинга

### 1. Few-shot Prompting

Бот автоматически извлекает примеры вопрос-ответ из базы знаний и включает их в промпт:

```
Примеры вопросов и ответов:
Q: Что такое Crimson Lens?
A: Crimson Lens - это способность линии Noctryn, которая появляется выборочно среди её членов...

Q: [запрос пользователя]
A: ...
```

**Преимущества:**
- Показывает модели желаемый формат ответа
- Улучшает качество генерации
- Примеры извлекаются автоматически из базы знаний

### 2. Chain-of-Thought (CoT)

Модель объясняет свои шаги рассуждения перед ответом:

```
[Шаги рассуждения]
1. Сначала я ищу информацию о Crimson Lens в предоставленных документах.
2. В документах указано, что Crimson Lens - это способность линии Noctryn.
3. Также найдено, что Crimson Lens даёт две основные способности.
4. Следовательно, ответ...

[Ответ]
Crimson Lens - это...
```

**Преимущества:**
- Повышает точность ответов
- Позволяет отследить логику модели
- Помогает модели лучше анализировать контекст

## Архитектура RAG-пайплайна

```
1. Запрос пользователя (может содержать оригинальные термины)
   ↓
2. Расширение запроса (замена терминов: Sharingan → Crimson Lens, если нужно)
   ↓
3. Поиск в векторном индексе (ChromaDB)
   ↓
4. Формирование промпта (термины остаются на языке нового мира):
   - System промпт (с CoT инструкциями)
   - Few-shot примеры
   - Контекст из базы знаний (термины нового мира)
   - Запрос пользователя
   ↓
5. Генерация ответа через LLM (OpenAI/Ollama)
   ↓
6. Возврат ответа пользователю (на языке нового мира)
```

## Настройка

### Изменение модели LLM

```python
# OpenAI
bot = RAGBot(llm_provider="openai", llm_model="gpt-4")

# Ollama (локально, бесплатно)
bot = RAGBot(llm_provider="ollama", llm_model="mistral")
```

### Изменение параметров генерации

```python
bot = RAGBot(
    temperature=0.5,      # Более детерминированные ответы
    max_tokens=1500,      # Более длинные ответы
    k_chunks=7           # Больше контекста
)
```

### Отключение техник промптинга

```python
# Без Few-shot и CoT
result = bot.generate_answer(
    query,
    use_few_shot=False,
    use_cot=False
)
```

## Производительность

## Ограничения

1. **OpenAI API** - требует API ключ и может иметь ограничения квоты

2. **Зависимость от качества индекса** - качество ответов зависит от качества векторного индекса из задания 3
3. **Стоимость API** - использование OpenAI API может быть платным
   - **Решение:** Используйте Ollama - полностью бесплатно

## Примечания

- **Термины нового мира:** Бот работает с онтологией нового мира из базы знаний. Все ответы используют термины нового мира (Crimson Lens, Kael Vexaris, Axiom, Pattern, Operative и т.д.), а не оригинальные термины
- **Расширение запросов:** Если пользователь задаёт вопрос с оригинальными терминами (например, "Sharingan"), бот автоматически расширяет запрос для поиска (Sharingan → Crimson Lens), но в ответе использует термины нового мира
- **Все ответы основаны только на информации из векторного индекса**
- **Бот честно признаёт, когда информации недостаточно**
- **Chain-of-Thought помогает улучшить качество ответов за счёт явного рассуждения**

## Устранение неполадок

### Ошибка: "API ключ OpenAI не найден" или "Превышена квота"
Решение: Используйте Ollama (бесплатно, без API ключей):
```bash
# Установите Ollama: https://ollama.ai
ollama serve
ollama pull mistral
$env:LLM_PROVIDER="ollama"  # Windows
export LLM_PROVIDER="ollama"  # Linux/Mac
```

### Ошибка: "Векторный индекс не найден"
Решение: Запустите `python build_index.py` для создания индекса

### Ошибка: "OpenAI не установлен"
Решение: Установите `pip install openai` (нужна даже для Ollama)

### Ошибка: "Connection refused" (Ollama)
Решение: Убедитесь, что Ollama запущен: `ollama serve`

### Медленные ответы
Решение: 
- OpenAI: Используйте модель `gpt-3.5-turbo` вместо `gpt-4`
- Ollama: Используйте меньшую модель (`llama3.2` вместо `mistral` или `llama3.1:8b`)
- Уменьшите `max_tokens`
