# Руководство по моделям для русского языка

## Проблема: смешение языков

Если модель генерирует ответы с смешением языков (например, "действительный персонаж... He имеет способность..."), это означает, что модель недостаточно хорошо работает с русским языком.

## Рекомендуемые модели для русского языка

### 1. OpenAI (лучший выбор для качества)

**GPT-4** или **GPT-4 Turbo** - лучший выбор для русского языка:
```python
bot = RAGBot(
    llm_provider="openai",
    llm_model="gpt-4"  # или "gpt-4-turbo-preview"
)
```

**Преимущества:**
- ✅ Отличное качество русского языка
- ✅ Грамматически правильные предложения
- ✅ Минимум смешения языков
- ✅ Хорошее понимание контекста

**Недостатки:**
- ❌ Дороже, чем GPT-3.5
- ❌ Требует API ключ

**GPT-3.5-turbo** - бюджетный вариант:
```python
bot = RAGBot(
    llm_provider="openai",
    llm_model="gpt-3.5-turbo"
)
```

**Преимущества:**
- ✅ Дешевле GPT-4
- ✅ Приемлемое качество русского

**Недостатки:**
- ❌ Может смешивать языки
- ❌ Менее грамматически правильные ответы

### 2. Ollama (бесплатно, локально)

#### Saiga модели (русскоязычные модели для Ollama)

**Важно:** Модели Saiga требуют ручной установки из Hugging Face. Проще использовать альтернативы ниже.

**Если хотите установить Saiga вручную:**
1. Скачайте модель с Hugging Face: https://huggingface.co/IlyaGusev/saiga_mistral_7b_gguf
2. Следуйте инструкциям по импорту в Ollama

**Рекомендуется использовать альтернативы:**

#### Альтернативные модели Ollama (работают с русским):

**Llama 3.1 8B** (лучший баланс для русского):
```bash
ollama pull llama3.1:8b
```

```python
bot = RAGBot(
    llm_provider="ollama",
    llm_model="llama3.1:8b"
)
```

**Mistral 7B** (хорошо работает с русским):
```bash
ollama pull mistral
```

```python
bot = RAGBot(
    llm_provider="ollama",
    llm_model="mistral"
)
```

**Llama 3.2** (быстрая, но хуже с русским):
```bash
ollama pull llama3.2
```

**Примечание:** Для лучшего качества русского языка рекомендуется использовать GPT-4 (OpenAI) или настроить промпт более строго.

### 3. YandexGPT (альтернатива)

YandexGPT специально оптимизирован для русского языка, но требует отдельной интеграции.

## Быстрое решение проблемы

### Вариант 1: Переключиться на GPT-4 (OpenAI)

```python
from rag_bot import RAGBot

bot = RAGBot(
    llm_provider="openai",
    llm_model="gpt-4",  # Вместо gpt-3.5-turbo
    api_key="your-api-key"
)
```

### Вариант 2: Использовать Llama 3.1 8B (Ollama) - лучшая доступная модель для русского

```bash
# 1. Установите Ollama: https://ollama.ai
# 2. Загрузите модель (лучше работает с русским, чем llama3.2)
ollama pull llama3.1:8b

# 3. Настройте переменную окружения
$env:LLM_PROVIDER="ollama"  # Windows
export LLM_PROVIDER="ollama"  # Linux/Mac

# 4. В коде укажите модель
bot = RAGBot(
    llm_provider="ollama",
    llm_model="llama3.1:8b"
)
```

**Альтернатива - Mistral 7B:**
```bash
ollama pull mistral
```

```python
bot = RAGBot(
    llm_provider="ollama",
    llm_model="mistral"
)
```

## Рекомендации

1. **Для продакшена:** GPT-4 или GPT-4 Turbo (лучший выбор)
2. **Для разработки/тестирования:** GPT-3.5-turbo (если бюджет ограничен)
3. **Для локального использования:** Llama 3.1 8B или Mistral 7B через Ollama
4. **Для максимального качества:** GPT-4 + улучшенный промпт

## Дополнительные улучшения

Промпт уже улучшен для лучшей работы с русским языком. Если проблемы остаются:

1. Увеличьте `max_tokens` для более полных ответов
2. Уменьшите `temperature` до 0.3-0.5 для более детерминированных ответов
3. Используйте более мощную модель (GPT-4 вместо GPT-3.5)

## Пример настройки для лучшего русского

```python
bot = RAGBot(
    llm_provider="openai",
    llm_model="gpt-4",  # Лучшая модель для русского
    temperature=0.5,    # Более детерминированные ответы
    max_tokens=1500     # Больше места для ответа
)
```
